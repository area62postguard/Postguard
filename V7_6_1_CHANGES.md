# PostGuard v7.6.1

- Updated PostGuard Personal to £49/month with unlimited pre-post scanning for every post the customer submits to PostGuard before publishing, plus risk analysis and advice.
- PostGuard Executive remains £199/month; package features are marked "Features to be confirmed".
- PostGuard VIP changed from £400/month to £499/month; package features are marked "Features to be confirmed".
- Updated the Terms pricing table to show VIP at £499/month.
- Stripe still controls the amount actually charged. Before accepting live VIP payments, create/select the £499 recurring Stripe Price and set `POSTGUARD_STRIPE_PRICE_VIP` to that new Price ID.
